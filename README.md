# 🛍️ E-Commerce Website

A simple and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* 🏠 Home page
* 👕 Men, Women, Kids & Accessories categories
* 🔥 New Trends / Sale section
* 🛒 Product browsing
* ✨ Interactive hover effects
* 📱 Responsive design
* 📄 Shop, Blog & Contact pages
* ⚡ JavaScript-based interactions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
